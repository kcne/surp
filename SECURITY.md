# Security policy

SURP is in production and stores passenger data. Please do not report
vulnerabilities in public issues.

## Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/kcne/surp/security/advisories/new)
on GitHub. Include what is affected, how to reproduce it, and the impact you
expect.

You will get an acknowledgement within a few working days. Fixes ship to the
latest version on `master`; older versions are not supported.
